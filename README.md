## Робочий процес (Git Flow)

1. `main` захищена: прямі push заборонені, лише через Pull Request.
2. Кожен працює у своїй гілці:
   ```bash
   git checkout -b feature/newton      # Діана
   git checkout -b feature/stirling    # Софія
   git checkout -b feature/simple      # Вільгельм
   ```
3. Коміти малі та з зрозумілими повідомленнями:
   ```bash
   git add newton.py
   git commit -m "Add Newton forward/backward derivative formulas (task 1.1)"
   git push -u origin feature/newton
   ```
4. Відкрити Pull Request у `main`, призначити ревʼюером Вільгельма.
5. Вільгельм перевіряє, залишає коментарі, робить merge.
6. Перед новою роботою синхронізуватися:
   ```bash
   git checkout main && git pull
   ```
